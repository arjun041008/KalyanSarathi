Description:

KalyanSarathi is an android application that creates a bilingual interface (English and Hindi) to advise users on government schemes they are eligible for. The application, will use a Gemini API and will first ask the user a series of question and then input it into the Gemini Prompt, which will be given I this document Additionally, it should consist of Text to Speech (TTS) and Speech to Text (STT) facilities, so that users can interact with the bot with audio.

User Experience Pipeline

1)	Home Page that greets users and takes them to the chatbot page
2)	Chatbot page opens with the placeholder text, after which the user gets asked a number of questions (See below) and can interact with the bot through audio or text. All messages should be read out for the user in either English or Hindi
3)	All page instruction change language with a toggle between English and Hindi.
4)	A page where previous chats are stored with the option of deleting chats
